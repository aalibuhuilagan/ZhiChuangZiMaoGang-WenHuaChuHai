最终提交的网页工程目录（多子页结构，2026-08-11 重构）。

```text
网页/
├── index.html            # 首页（Hero + 图标导览）
├── ip.html               # 子页：IP 形象馆

├── voices.html           # 子页：多语之声
├── about.html            # 子页：创作说明
├── product.html          # 子页：IP 手办商店（3D 展示 + 下单流程）

└── assets/               # 素材按板块细分：
    ├── hero/             # Hero 主视觉
```

规则：素材先入 `IP形象/`、`漫画/`、`视频/` 等原始目录，确认定稿后再复制进 `assets/` 对应目录，避免网页目录混乱。

页面导航说明（2026-08-11 v1.4）：
- 顶部菜单 5 主菜单：IP形象馆 / IP漫画（悬停/点击展开，纯下拉不跳转；子项=故事一·二·三独立页）/
  IP视频 / 更多内容（下拉：小游戏·表情包·节气海报·落地蓝图[二级子菜单：6 子页]·多语之声）/ 创作说明；
